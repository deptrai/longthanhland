## Findings

### E1 — Dev mode hydration error (legacyBehavior) — MEDIUM (dev experience)

- **File:** `bdsai/apps/web/components/shared/site-header.tsx:38`
- **Mô tả:** `<Link href={item.href} legacyBehavior passHref>` gây hydration error trong **dev mode** (`yarn dev` — Turbopack). Console error:
  ```
  Error: `<Link legacyBehavior>` received a direct child that is either a Server Component,
  or JSX that was loaded with React.lazy(). This is not supported.
  Either remove legacyBehavior, or make the direct child a Client Component.
  ```
  Page hiển thị "This page couldn't load" (React error boundary, `html id="__next_error__"`). Header/footer/main KHÔNG render trong browser ở dev mode.
- **Production build (`yarn start`):** KHÔNG bị lỗi — page render đầy đủ (static prerender `○ Static`). Tất cả browser test PASS với production build.
- **Root cause:** `NavigationMenuLink` (shadcn/Radix) là Server Component, được dùng làm direct child của `<Link legacyBehavior>`. Next 16 + React 19 không hỗ trợ `legacyBehavior` với Server Component child trong dev mode (Turbopack).
- **Severity:** MEDIUM — không ảnh hưởng production deploy (Vercel dùng production build), nhưng break dev experience (developer không thể xem page trong dev mode).
- **Review log L1:** Đã ghi nhận là "deprecation warning" (LOW) — **thực tế nghiêm trọng hơn** (break page hoàn toàn trong dev, không chỉ warning). Đề xuất upgrade L1 → MEDIUM và fix trước handoff.
- **Cách sửa (from review L1):**
  ```tsx
  <NavigationMenuItem key={item.href}>
    <NavigationMenuLink asChild className={navigationMenuTriggerStyle()}>
      <Link href={item.href}>{item.label}</Link>
    </NavigationMenuLink>
  </NavigationMenuItem>
  ```
  (Bỏ `legacyBehavior passHref`, dùng `NavigationMenuLink asChild` wrap `<Link>`.)
